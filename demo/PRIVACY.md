# Persistence Lab data

Persistence Lab stores databases on your device or in your browser's origin-private storage.
It does not send note contents, queries, or database files to a service and contains no
analytics or advertising integration. Named databases remain until you remove the app's data
or browser site storage. In-memory databases disappear when closed.

The SQL log and developer console may contain the SQL and record values you enter. Copying or
exporting JSON shares data only with the destination you choose. Scripted test runs may save
screenshots and logs on the development machine or CI runner; use synthetic data for these runs.
