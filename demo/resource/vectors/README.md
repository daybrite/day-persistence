# Vector glyphs

The toolbar glyph is a [Material Symbol](https://fonts.google.com/icons) (Outlined, weight 400,
24 px), copied from Google Fonts as a single-path SVG and renamed for what the app uses it for.
Day stages it as a template glyph, so each toolkit tints it to its own bar.

| File | Material Symbol | Used for |
|---|---|---|
| `console.svg` | `dock_to_bottom` | the toolbar toggle that shows and hides the SQL log |

(https://github.com/google/material-design-icons/blob/master/LICENSE). The file carries no Day
copyright header: it is Google's art, vendored as is.
